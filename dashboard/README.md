# Dashboard

Web app Apps Script che legge il foglio hub e mostra:

1. **Stanotte**: sleep score, ore dormite, HRV, battito a riposo, CO2 media e massima,
   temperatura media della camera, con confronto rispetto alla propria media.
2. **La notte in un grafico**: CO2 e temperatura dalle 22 alle 10, con le fasi del sonno Garmin.
3. **Cosa influisce sul sonno**: confronti automatici (es. sleep score con CO2 sopra o sotto 1000)
   e grafico a punti sleep score rispetto alla CO2 media notturna.
4. **Trend 30 e 90 giorni**: sleep score, HRV, CO2 notturna, peso.
5. **Corpo e attività**: peso e % grasso (Renpho), passi, stress, Body Battery (Garmin).

Da costruire: prima un prototipo grafico, poi la web app collegata al foglio.
